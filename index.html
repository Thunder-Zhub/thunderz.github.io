How to join

  1. Open Minecraft Java Edition Launch version 1.12 or newer.
  2. Add the server Go to Multiplayer, then choose Add Server.
  3. Enter the address and play Type zorin.pxlmc.com, save, and join.

Server rules

  • No griefingLeave other players' builds as you found them.
  • No stealingIf it isn't yours, don't take it, claimed or not.
  • No cheating or X-rayHacked clients and X-ray packs are not allowed.
  • Be respectfulTreat everyone kindly in chat and in game.
  • No lag machinesKeep farms and redstone friendly to the server.
